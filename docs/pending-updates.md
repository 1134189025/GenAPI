# 待更新事项

本文记录后续版本的产品更新建议，作为开发排期和需求细化的候选池。

## 用户建议

1. 签到功能（0.1.8 已实施）
   - 用户每天签到后获得普通图片额度奖励。
   - 签到记录写入现有运行时数据库 `data/users.db` 的 `daily_checkins` 表，同一用户每天只能领取一次。
   - 后台可配置签到开关、每日普通图片额度、连续签到奖励和签到时区。
   - 签到日历、活动任务、排行榜、会员额度奖励或更多活动奖励仍可作为后续增强项。

2. 指定分辨率（0.1.10 已实施固定预设）
   - 用户在生图时可以选择目标分辨率预设。
   - 当前固定预设：`1024x1024`、`1536x864`、`864x1536`、`1280x960`、`960x1280`。
   - 生成结果和图库会展示目标尺寸与实际图片尺寸。
   - 自定义宽高、严格裁剪/缩放和像素级保证暂不纳入当前版本。

3. 生图提示词模板广场
   - 提供可浏览、搜索和使用的提示词模板。
   - 用户可从模板快速填充提示词并发起生图。

4. 图库
   - 服务端保存用户生成的图片一段时间。
   - 用户可在登录后查看、下载和继续编辑近期生成图片。
   - 当前 P0 实施范围：私有用户图库，默认保存 7 天，分享功能仅预留字段。

5. 用户图片分享广场
   - 用户可把已生成图片发布到公开广场页面。
   - 其他用户可以浏览公开分享的图片。

## 初步优先级建议

- P0：图库（0.1.9 已实施私有图库闭环，0.1.10 补充分辨率元数据展示）
- P1：指定分辨率（0.1.10 已实施固定预设）
- P2：生图提示词模板广场、用户图片分享广场

## 后续细化问题

- 签到功能已在 0.1.8 实施，后续可继续细化签到日历、活动任务、排行榜、会员额度奖励或更多活动奖励。
- 图库保存时长默认设置为多少天。
- 分享广场是否需要管理员审核后才公开。
- 提示词模板由管理员维护，还是允许用户投稿。
- 指定分辨率后续是否开放自定义宽高，以及是否需要生成后裁剪/缩放。
