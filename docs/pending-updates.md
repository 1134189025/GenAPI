# 待更新事项

本文记录后续版本的产品更新建议，作为开发排期和需求细化的候选池。

## 用户建议

1. 签到功能
   - 用户每天签到后获得奖励。
   - 后续需确定奖励类型，例如图片额度、会员额度、连续签到奖励或活动奖励。

2. 指定分辨率
   - 用户在生图时可以选择或输入目标分辨率。
   - 后续需确认上游能力边界，以及与现有图片比例参数的关系。

3. 生图提示词模板广场
   - 提供可浏览、搜索和使用的提示词模板。
   - 用户可从模板快速填充提示词并发起生图。

4. 图库
   - 服务端保存用户生成的图片一段时间。
   - 用户可在登录后查看、下载和继续编辑近期生成图片。
   - 当前 P0 实施范围：私有用户图库，默认保存 7 天，分享功能仅预留字段。

5. 用户图片分享广场
   - 用户可把已生成图片发布到公开广场页面。
   - 其他用户可以浏览公开分享的图片。

## 初步优先级建议

- P0：图库（本次已实施私有图库闭环）
- P1：指定分辨率、签到功能
- P2：生图提示词模板广场、用户图片分享广场

## 后续细化问题

- 签到奖励是否直接发放普通图片额度。
- 图库保存时长默认设置为多少天。
- 分享广场是否需要管理员审核后才公开。
- 提示词模板由管理员维护，还是允许用户投稿。
- 指定分辨率采用固定选项，还是允许自定义宽高。
