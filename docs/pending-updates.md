# 待更新事项

本文仅记录尚未完成、仍需要排期或继续细化的产品更新建议。已上线的事项不再保留在主待办列表中。

## 待开发事项

1. P1: 用户图片分享广场
   - 用户可把已生成图片发布到公开广场页面。
   - 其他用户可以浏览公开分享的图片。
   - 需要补充公开状态、下架、举报、审核和基础排序规则。

2. P2: 生图提示词模板广场
   - 提供可浏览、搜索和使用的提示词模板。
   - 用户可从模板快速填充提示词并发起生图。
   - 模板需要支持分类、标签、预览效果和一键套用。

## 后续增强候选

- 签到进阶玩法：签到日历、活动任务、排行榜、会员狗狗币奖励或更多活动奖励。
- 分辨率进阶能力：自定义宽高、严格裁剪/缩放和像素级尺寸保证。
- 图库进阶能力：更长期保存策略、批量管理、图片复用和与分享广场的发布流程打通。

## 初步优先级建议

- P1：用户图片分享广场。
- P2：生图提示词模板广场。
- P3：签到、分辨率和图库的进阶增强。
